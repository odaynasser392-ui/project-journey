# رحلة مشروع | Project Journey

تطبيق ويب بثلاث لغات: العربية والإنجليزية والإسبانية. الكود مفتوح وغير مشفر أو مضغوط.

## التشغيل

1. ثبّت Node.js 18 أو أحدث.
2. افتح المجلد في VS Code.
3. نفّذ:

```bash
npm install
npm start
```

4. افتح: `http://localhost:3000`

تُنشأ قاعدة SQLite تلقائيًا عند أول تشغيل، وتبدأ دون مستخدمين أو قصص أو مشاريع وهمية.

## حساب المشرف

أول مستخدم يتم إنشاؤه يكون مستخدمًا عاديًا. لجعل مستخدم مشرفًا نفّذ في SQLite:

```sql
UPDATE users SET role='admin' WHERE email='your@email.com';
```

## الذكاء الاصطناعي

الواجهة مهيأة للربط بمفتاح API داخل `.env`. دون المفتاح تعمل الاقتراحات المحلية المبنية على نص القصة أو المشروع، ولا تعرض بيانات مختلقة.
